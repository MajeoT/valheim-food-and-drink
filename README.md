# Valheim Mead & Feast Planner

Single-file React app for planning three-food Valheim meals and browsing foods and meads by biome, Meadows through the Deep North.

Open `index.html`, or visit the GitHub Pages site for this repo. No build step: React, Tailwind, Framer Motion and Lucide load from CDNs.

Stats follow community sources and may lag behind patches.
